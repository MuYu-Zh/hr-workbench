# 组织架构 + 花名册变更 + xlsx 批量导入 设计文档

日期：2026-08-17  
状态：已确认  
方案：A（沿用原生 JS 架构，自绘轻量组织树 + 本地 SheetJS）

## 1. 背景与目标

当前 `hr-workbench` 为纯前端、本机存储的个人 HR 工作台。本次需求包含：

1. 新增“组织架构”模块：
   - 用户可维护公司组织树结构。
   - 可点击“预览”以组织结构图形式查看组织树。
   - 组织结构图支持浏览器内全屏。
2. 变更“人员花名册”模块：
   - 人员信息不再需要“岗位”和“职级”两个属性。
   - 人员信息维护时，“部门”属性引用组织架构模块维护的数据。
   - 花名册支持 `.xlsx` 文件批量导入。
3. 组织删除规则：
   - 删除组织节点时，若该组织下有花名册人员关联，则禁止删除。
   - 若该组织下有子节点，同样禁止删除，需先移动或删除子节点。

## 2. 方案选择

采用方案 A：

- 继续使用现有原生 HTML/CSS/JS 零构建架构。
- 组织树继续使用现有 `department` 表，通过 `parentId` 表达层级。
- 组织架构图使用 HTML/CSS + SVG 自绘，不引入第三方图表库。
- `.xlsx` 解析使用本地内置 SheetJS（`xlsx.full.min.js`），保证 PWA 离线可用。
- 彻底移除岗位/职级表、种子数据和所有 UI 引用。

## 3. 数据模型与存储迁移

### 3.1 组织架构节点

继续使用 `department` store，字段：
不内置默认组织树，初始为空，由用户自行维护。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识 |
| `name` | string | 组织名称 |
| `parentId` | string/null | 上级组织 id，null 表示顶级 |
| `sortOrder` | number | 同级排序 |
| `status` | string | `normal` / `disabled` |
| `createdAt` | number | 创建时间 |
| `updatedAt` | number | 更新时间 |
| `deleted` | number | 软删除标记，0 正常，1 已删除 |

### 3.2 移除岗位/职级

- 删除 `position` store。
- 删除 `grade` store。
- 删除 `seed.js` 中的默认岗位、默认职级种子数据。
- 删除 `employee` 上的 `positionId`、`gradeId` 字段。
- 删除花名册、员工详情、员工编辑、筛选、CSV 导出中的“岗位 / 职级”相关逻辑。

### 3.3 数据库升级

- `db.js` 的 `DB_VERSION` 从 `1` 升到 `2`。
- 升级脚本：
  1. 读取旧 `employee` 数据。
  2. 删除旧 `employee` store。
  3. 按新结构重建 `employee` store（去掉 `positionId` / `gradeId`）。
  4. 将旧员工数据写回新 store，保留 `departmentId` 等其余字段。
  5. 删除 `position`、`grade` 两个 store。
- 已有本地数据不丢失，仅清理岗位/职级字段。

### 3.4 删除组织节点规则

删除前检查：

1. 该节点下没有直接关联员工。
2. 该节点没有子节点。

任一条件不满足则禁止删除，并提示具体原因：

- 有员工：提示“该组织下存在员工，请先调整员工部门”。
- 有子节点：提示“该组织存在子组织，请先移动或删除子组织”。

## 4. 组织架构模块

### 4.1 菜单

- 将现有“组织架构管理”占位分组改为一个一级页面“组织架构”。
- 路径：`/org`。
- 不再保留“部门设置与调整 / 岗位职级体系 / 组织架构图”三个占位入口。

### 4.2 页面布局

- 组织树列表：
  - 缩进展示层级。
  - 每行显示：名称、状态（正常/停用）、排序。
  - 操作：新增子节点、编辑、停用/启用、删除、预览。
- 顶部按钮：
  - 新增顶级组织。
  - 预览组织架构图。
  - 展开/收起全部。

### 4.3 新增/编辑节点

弹窗字段：

- 组织名称（必填）。
- 上级组织（下拉选择，顶级可为空）。
- 排序号。
- 状态（正常 / 停用）。

上级下拉约束：

- 编辑时不能选择自己。
- 不能选择自己的后代节点，避免形成环。

### 4.4 预览组织架构图

- 点击“预览”后打开全屏浮层。
- 根据 `department` 树生成树形结构图：
  - 根节点在上，子节点向下展开。
  - 节点显示组织名称。
  - 停用节点加灰色标识。
  - 同一父节点下按 `sortOrder` 排序。
- 使用 HTML/CSS + SVG 自绘。
- 全屏交互：
  - 使用浏览器 Fullscreen API。
  - 浮层内提供“进入全屏 / 退出全屏”按钮。
  - 不支持全屏时自动降级为普通大弹窗。

## 5. 花名册变更

- 移除员工编辑表单中的“岗位”“职级”。
- 移除花名册列表、员工详情、离职档案、筛选下拉中的“岗位”“职级”。
- 部门字段保留，并引用组织架构模块维护的组织树。
- 部门下拉选项来自 `department` 表；停用节点加标识展示。
- CSV 导出同步移除“岗位 / 职级”列。

## 6. xlsx 批量导入

### 6.1 入口

- 花名册页面增加按钮：
  - 导入 .xlsx
  - 下载导入模板

### 6.2 本地 SheetJS

- 将 `xlsx.full.min.js` 放入 `vendor/xlsx.full.min.js`。
- 在 `index.html` 中通过 `<script>` 引入。
- 同步加入 `sw.js` 的 `STATIC_ASSETS`，保证 PWA 离线可用。
- 仅用于导入解析与模板生成，不改变现有零构建架构。

### 6.3 导入模板列

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 工号 | 是 | 唯一匹配键 |
| 姓名 | 是 | 员工姓名 |
| 性别 | 否 | 男/女 |
| 民族 | 否 | |
| 出生日期 | 否 | |
| 身份证号 | 否 | |
| 手机 | 否 | |
| 邮箱 | 否 | |
| 部门 | 否 | 填组织树中的名称 |
| 入职日期 | 否 | |
| 转正日期 | 否 | |
| 用工形式 | 否 | |
| 学历 | 否 | |
| 毕业院校 | 否 | |
| 专业 | 否 | |
| 现住址 | 否 | |

### 6.4 导入规则

- 按“工号”匹配：
  - 已存在：更新该员工。
  - 不存在：新增员工。
- 部门按名称匹配组织树：
  - 匹配不到时该行部门留空，并在结果中提示。
- 必填项缺失、日期格式错误等：
  - 在结果中标记失败原因。
  - 不阻断其他行导入。

### 6.5 导入结果

导入完成后展示：

- 成功新增 N 条。
- 成功更新 N 条。
- 部门未匹配 N 条。
- 失败 N 条（附行号和原因）。

## 7. 涉及文件（预期）

- `js/db.js`：DB_VERSION、store 定义、升级迁移。
- `js/seed.js`：移除岗位/职级种子，调整默认部门种子。
- `js/router.js`：菜单调整，新增 `/org` 路由。
- `js/pages/org.js`：新增组织架构维护页。
- `js/pages/employee.js`：移除岗位/职级，部门引用组织树，新增 xlsx 导入与模板下载。
- `js/pages/settings.js`：CSV 导出字段调整（如保留）。
- `js/pages/dashboard.js`：移除岗位/职级相关查询与展示。
- `index.html`：引入 `vendor/xlsx.full.min.js`。
- `vendor/xlsx.full.min.js`：本地 SheetJS 库。
- `sw.js`：静态资源清单加入 xlsx 库。
- `css/style.css`：组织树、组织架构图、导入结果样式。

## 8. 不在本期范围

- 组织架构图导出图片。
- 拖拽调整组织层级。
- 岗位/职级体系保留或迁移到其他模块。
- 花名册 xlsx 导出。
- 多用户/权限体系。

## 9. 测试要点

- 数据库升级后旧员工数据保留，`positionId` / `gradeId` 被清理。
- 组织树新增/编辑/移动/停用/删除流程正常。
- 删除有员工或子节点的组织时被禁止并提示。
- 组织架构图预览与浏览器全屏正常。
- xlsx 模板下载、按工号更新/新增、部门匹配、错误行提示正常。
- PWA 离线环境下 xlsx 导入仍可用。
